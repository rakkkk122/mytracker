# MyTracker 📱

**MyTracker** adalah aplikasi Android yang dirancang untuk membantu pengguna membangun kebiasaan baik, mengatur rencana harian, dan mengelola keuangan pribadi dalam satu tempat.

Tujuannya adalah menjadikan kehidupan sehari-hari lebih teratur, produktif, dan bijak secara finansial melalui pengalaman aplikasi seluler yang sederhana dan intuitif.

---

## ✨ Fitur

### 🎯 Pelacak Kebiasaan Baik (Good Habit Tracker)
* Melacak kebiasaan harian dan membangun rutinitas positif.
* Memantau perkembangan kebiasaan.
* Tetap konsisten dengan target pribadi.

### 📅 Perencanaan Harian (Daily Planning)
* Mengatur aktivitas dan rencana harian.
* Mengelola tugas dan jadwal pribadi.
* Memantau target dan prioritas harian.

### 💰 Pelacak Keuangan Pribadi (Personal Finance Tracker)
* Mencatat pemasukan dan pengeluaran pribadi.
* Memantau aktivitas keuangan harian.
* Mengelola anggaran pribadi.
* Mengontrol kebiasaan belanja dengan lebih baik.

---

## 🎨 Desain

MyTracker hadir untuk memberikan antarmuka yang bersih, modern, dan ramah pengguna:

* Navigasi yang sederhana dan intuitif.
* Desain UI Android yang modern.
* Fokus pada keterbacaan dan kemudahan penggunaan.
* Dirancang untuk mempermudah pencatatan harian.

## 🚀 Memulai (Getting Started)

Ikuti langkah-langkah berikut untuk menjalankan MyTracker secara lokal:

1. **Kloning repositori ini:**
   ```bash
   git clone https://github.com/rakkkk122/mytracker.git
   ```
2. **Buka proyek** menggunakan Android Studio.
3. **Tunggu hingga proses Gradle Sync** selesai.
4. **Hubungkan perangkat Android** atau jalankan emulator.
5. **Klik Run** untuk membangun dan menjalankan aplikasi.
